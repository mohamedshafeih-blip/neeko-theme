# Neeko theme

Lightweight custom WordPress theme for neeko.my (no page builder).

- `front-page.php`: homepage
- `page-website-design.php`, `page-seo.php`: service pages (the page slug picks the template)
- `assets/css/site.css`: shared styles; `assets/css/svc-*.css`: per service page
- `parts/`: header, footer, icon sprite, per-page meta and schema

Activating the theme creates the Home, Website design and SEO pages and sets Home as the front page.
